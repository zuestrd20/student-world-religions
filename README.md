# 世界宗教小百科｜學生探索指南

給高中程度讀者的繁體中文教育導覽。介紹主要宗教傳統、起源與歷史、內部差異、爭議、全球與國別分布、臺灣現況，以及高控制行為與求助。

## 開啟與部署

這是無外部執行期依賴的純靜態網站。不需金鑰、登入、資料庫或建置服務。將本目錄部署為 GitHub Pages 根目錄即可。所有資產使用相對路徑，支援子目錄網址。

本機閱讀可直接開啟 `index.html`；或於本目錄執行 `python -m http.server 8000`，再開啟 `http://localhost:8000`。若環境禁止本機瀏覽器連線，不應繞過限制；改以已授權的公開部署進行實際 UI 檢查。

## 資料與內容

- `data/世界宗教導覽資料.json`：完整繁體中文導覽資料與來源索引，可從網頁下載。
- `data/content.js`：與 JSON 相同的資料，包為網站可直接讀取的腳本，避免本機檔案模式的跨來源限制。
- 宗教內容按主題查閱；以 `#religion/主題識別碼` 分享詳情。
- `app.js`：互動、搜尋、分類、詳情、人口圖表及來源篩選。
- `assets/compass.svg` 與首頁地球插圖：原創 SVG 視覺。

## 年份與方法

內容查核：2026-10-04。全球與12個選錄國家／地區的比較一律使用 Pew Research Center 2020 年估計（研究發表於2025年；資料包於2026年新增指標）。這不是2026年即時人口數。

全球七類資料主要量測宗教認同。錫克教、道教、神道等可能併入「其他宗教」，未單列不代表零。無宗教歸屬不代表沒有儀式、靈性或信念。百分比顯示官方四捨五入值，小於0.1%保留「<0.1%」；不以圖形顯示精度取代資料精度。

臺灣另列2023年成年人調查、2024年發表的結果。其年份、母體與問法不同，不能直接與2020年全人口估計相減當作趨勢。五項顯示百分比共98%，原圖未列不知道／拒答且有四捨五入，不補造剩餘類別。寺廟或組織登記數不等於信徒數。

宗教介紹不是教義的唯一解釋；爭議敘述針對特定歷史、制度或行為，不概括所有成員。高控制警訊不是診斷量表或法律定義，也不能拿來計分判定某團體。來源類型依製作者與用途人工標示，非依網域猜測。

## 驗證

需 Node.js 18 或以上，無須安裝套件：

    node --check app.js
    node tests/validate.cjs

檢查來源識別碼、主張來源對帳、人口合計／分類／年份／小值、臺灣98%限制、搜尋、篩選、同步重設、深鏈、無效連結、Escape關閉邏輯、本地資產與模擬DOM。模擬DOM不是完整瀏覽器，不代表已通過視覺、焦點循環、窄螢幕或真實剪貼簿測試；公開部署後仍需實測。

## 更新公開資料

修改 `data/世界宗教導覽資料.json` 後執行：

    python tools/sync_data.py
    node tests/validate.cjs

確認每個主張有相符來源，保留統計年份、單位、母體與限制；更新時同步調整 `index.html` 的資產版本查詢參數，以免瀏覽器使用舊快取。
